# AI Agent Thermal Test

Исследовательский Streamlit-прототип для тепловизионной оценки разъёмных контактных соединений.

> Программа не управляет электрооборудованием и не заменяет решение ответственного инженера. Пороги и модель должны быть утверждены эксплуатирующей организацией.

## Что изменено

- Статус рассчитывается локально и не зависит от LLM.
- При нагрузке ниже 30% выводится «Недостаточно данных», а не «Норма».
- `K_def` сравнивает перегрев контакта с перегревом исправного эталонного участка.
- Выводится 95%-й интервал неопределённости `K_def`.
- Удалены некалиброванные «остаточное усилие пружины» и «индекс окисления».
- Поддерживаются радиометрические FLIR/DJI RJPEG и ручной выбор ROI.
- Контакт и исправный эталон выделяются мышью двумя отдельными прямоугольниками; расчёт блокируется до подтверждения зон.
- Обычные PNG/JPEG показываются только для просмотра: температура по цветовой палитре не выдумывается.
- Добавлена физическая суррогатная модель, откалиброванная по 25 расчётам COMSOL 6.4.
- Программа прогнозирует максимальную температуру по току и `Rc`, оценивает `Rc` по термограмме и показывает расхождение измерения с моделью.
- LLM опционален; по умолчанию используется `openai/gpt-oss-20b` на Groq со строгой JSON Schema.

## Расчёт

При нагрузке не менее `0.3 * I_nom`:

```text
ΔT_contact   = T_contact - T_ambient
ΔT_reference = T_reference - T_ambient
K_def = ΔT_contact / ΔT_reference
ΔT_nom = ΔT_contact * (I_nom / I_actual) ** n
```

`T_reference` должна относиться к исправной соседней фазе, однотипному соединению или участку проводника в сопоставимых условиях. Показатель `n=2` является настраиваемым и должен калиброваться на данных конкретного типа оборудования.

### Суррогат COMSOL

Для текущей геометрии двух медных шин выполнена сетка из 25 стационарных расчётов:

- ток: `100, 200, 300, 400, 500 A`;
- контактное сопротивление: `5, 10, 20, 50, 100 мкОм`;
- температура воздуха: `20 °C`.

Аппроксимация максимальной температуры:

```text
T_max = T_ambient + I**2 * (7.8217159e-5 + 6.5289004e-6 * Rc_uohm)
```

Коэффициент детерминации `R²=0.999999998`, максимальная ошибка относительно таблицы COMSOL — около `0.005 °C`. Исходные 25 точек сохранены в `thermal_diagnostics/data/comsol_contact_sweep.csv` и проверяются автоматическим тестом.

Обратная формула оценивает контактное сопротивление по температуре горячей точки. Это оценка для заданной геометрии и условий теплоотдачи, а не замена микроомметра. Диапазон калибровки — `100…500 A`, `5…100 мкОм`; выше `120 °C` требуется модель с температурными свойствами, излучением и изменением состояния контакта.

Интерфейс по умолчанию использует контрольную точку `400 A` и не показывает
экстраполированный результат без явного разрешения пользователя. Кнопка
«Подставить контрольный пример COMSOL» загружает проверочный набор `400 A`,
`20 мкОм`, `20 °C` и `53,41 °C`. Расхождение выводится по модулю вместе с
текстовым пояснением, какая температура выше.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
streamlit run atc_agent.py
```

Для радиометрических JPEG нужен ExifTool:

```bash
# Debian/Ubuntu
sudo apt install libimage-exiftool-perl
```

На Streamlit Community Cloud он устанавливается из `packages.txt`.

### Выбор зон на термограмме

1. Выберите «Контакт» и обведите исследуемое соединение мышью.
2. Выберите «Исправный эталон» и обведите сопоставимый исправный участок.
3. Убедитесь, что зелёная и голубая области не пересекаются.
4. Подтвердите зоны — только после этого программа использует извлечённые температуры в расчёте.

Кнопка подсказки самой горячей области не выполняет распознавание оборудования и служит только начальным приближением.

## Ключ Groq

Приложение работает без ключа. Для опциональной редактуры отчёта задайте:

```toml
# .streamlit/secrets.toml — файл не должен попадать в Git
GROQ_API_KEY = "..."
```

Никогда не вставляйте API-ключ в `atc_agent.py`.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

## Ограничения

- По одной термограмме нельзя достоверно различить окисление, загрязнение и ослабление контактного нажатия.
- Для уточнения причины нужны измерения переходного сопротивления, контактного усилия и тренд предыдущих обследований.
- Радиометрическая точность зависит от коэффициента излучения, отражённой температуры, расстояния, влажности и калибровки камеры.
- Суррогат COMSOL применим к откалиброванной геометрии шин и принятому коэффициенту теплоотдачи; для другого оборудования коэффициенты необходимо пересчитать.
